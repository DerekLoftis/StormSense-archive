## StormSense Latest (2026-10-14)
Public repo DerekLoftis/StormSense-latest (Derek created it; saved to project; Pages via Actions), https://derekloftis.github.io/StormSense-latest/. publish.py fetches web4 Tidewatch files as placeholders, styles them with the vendored styler (--brand=stormsense, NWS flood thresholds on NAVD charts, only MLLW datum line on NAVD), renames to fore72/7day/30day (was fore56)/<ST>_<prod>_<MLLW|NAVD>.{html,csv}; cron 20 0,6,12,18; nothing archived; build_log.txt published. Thresholds: make_thresholds.py from NWPS gauge API (stations_nws.csv from surge_guidance/station_coverage.csv), fallback thresholds.json; MLLW gauges moved to NAVD with Tidewatch's CSV offset; NWPS colors Action #FFFF00, Minor #FF9900, Moderate #FF0000, Major #CC33FF (from water.noaa.gov hydrograph bundle). USLN/USLR gauge datum inferred MLLW. All reference-line labels click to hide/show (also in tidewatch_latest). web4's 30d folder has stale *_30d_NAVD_hc.html pages that shadowed the real NAVD page; fixed in style_pages.py. tidewatch_latest publishes style_log.txt. Workflow/job logs aren't readable from the sandbox (nor artifacts); check live pages via fetch-urls, and a failed StormSense build posts its log tail as a 'build failed' check-run annotation (readable via REST).

P-ETSS (2026-10-15, Derek's ask): petss.py pulls the newest GOOD NOMADS cycle (csv.tar.gz + shef.tar.gz; NOMADS keeps 2 days); 21 stations matched via SHEF mean. fore72 = 72 h at 6 min, hourly non-tidal parts low-passed (3 h Hann) onto P-ETSS 6-min tide, aligned to gauge obs (median over prior 24 h; est sites differ up to 0.75 ft); 10-90% cone rgba(20,38,96,0.5); m30 removed. fore72 CSV: date_time, astro_tide, surge, bias (applied = TWL-TIDE-SURGE; est sites' BIAS column is unapplied diagnostic), residual, SSforecast, SSforecast_p10/p90, surge_p10/p90; fallback stations keep Tidewatch 36 h. 7day = last 7 d from 30d+3d; 7day/30day CSV: date_time, water_level_ft (Tidewatch-captured gauge obs), astro_tide, residual; tide from P-ETSS (~6 d) plus CO-OPS predictions at NOAA ids (match P-ETSS to 0.012 ft), blank otherwise. 2026-10-15 22Z (Derek): field names carry units (date_time_z, *_ft); every CSV has a .json twin (metadata header + records, null for blanks); NN01-10, VB01-10, USNW, USPF, USSV dropped (DROP in publish.py; 35 stations). Six metadata PDFs + JSON twins (MLLW and -NAVD) in repo metadata/, rebuilt by tools/make_metadata.py SAMPLES_DIR (screenshots + sample CSVs), copies in /mnt/project-files/stormsense-latest/metadata/. PDFs use Liberation Sans (Arial metric clone; real Arial unobtainable, SourceForge blocks Actions).
