- Derek's five goals (2026-10-06): 1 automated archive (f36 at 00/06/12/18Z, 3d daily at 00Z, 30d on the 1st and 15th, NWS/NWPS 6-hourly; csv required, html and jpg valued); 2 ASA (comparison plot, regression plot, 31-day station table, all-station table, pptx); 3 site-specific Tidewatch Skill score with sensitivity analysis, plus overlapping 3d/30d validation plots; 4 predictor-corrector offset with m30 (on hold until the archive is long enough); 5 other surge guidance and an ensemble.
- Ensemble vision (Derek 2026-10-16): a second StormSense product plotting every guidance source on one chart, with its own archive; the primary StormSense forecast then adaptively switches to the best model and names it below the disclaimer, chosen from recent skill, analog past weather per site, each model's forcing strengths vs current conditions (rain-aware vs hydrodynamic surge), and other factors (P-Surge, tide+residual baseline, skill-weighted blending, high-tide timing/threshold scoring, run freshness, bad-gauge exclusion, river flow, seasonal sea level). Phase 1 live; phase 2 (skill-based pick per 0-12/12-36/36-72 h lead, switch after two updates in a row; one line in guidance.json) needs a week of ensemble archive (~2026-10-23); phase 3 (rain/hurricane/nor'easter rules) needs nothing from Derek; phase 4 (learning from past events) uses the archive bucket. Embeddable interactive archive waits on Derek: create a public-read Cloudflare R2 (or VIMS S3) bucket, add its key as repo secrets, create empty public repo StormSense-archive; then the archive thread saves every run and builds an iframe viewer for pages like https://www.vims.edu/people/loftis_jd/StormSense/forecasts/noaa/swpt/.

## Station and datum findings
- Retired stations (Derek 2026-10-15): NN01-NN10, VB01-VB10, USNW, USPF, USSV; removed project-wide (archiver, ASA, datum styling, StormSense skip them). Don't reintroduce them.
- Aliasing (tidewatch-asa/output/aliasing/ALIASING.md): Tidewatch publishes identical obs under several IDs (DAHL/USNC/USSC, WADC/USAR/USBK, USFM/USCB, USSF/USNR, USHR/USSB, GS01/GS02). DAHL's obs are New Market Creek's (forecast ~half a tide out of phase vs real Dahlgren); WADC similar; USSB, USCB, USNR aren't their sites. GS01/GS02's series is GS02's (Derek confirmed). USBB repeats values in ~18-min steps. Leave Tidewatch's DAHL and WADC out of source comparisons. USLI's f36 px30 is empty.
- Datum charts ([[tidewatch-datum-charts]]): NOAA stations on NOAA datums; USGS IDs plus GS01/GS02 on VDatum. Derek's style: m30 in VIMS teal #16687E, "Disclaimer: Tidewatch Charts™ are automated storm tide forecasts; User assumes all risk", 50% VIMS logo in first clear corner. 2024 Virginia VDatum puts NAVD88 ~1 ft too high (corrected). Tidewatch's MLLW-NAVD offsets differ slightly from NOAA's (DAHL 0.12, WMPT 0.05, BISH/YRCG 0.04, WACH 0.03 ft). GS01, GS02, CNRC are GreenStream sensors; the GreenStream API needs Derek's key, but CNRC's public VDEM page works without one (see CNRC above).
